# Manual Técnico

## Arquitectura
El sistema sigue una arquitectura por capas: Entidad, DAO, Negocio y Presentación.

## Clases
- Producto: modelo de datos
- ProductoDAO: interfaz de acceso a datos
- ProductoDAOImpl: persistencia en archivo
- ProductoService: reglas de negocio
- Main: interacción con el usuario

## Flujo
El usuario interactúa con Main, que llama a ProductoService, el cual utiliza ProductoDAO para acceso a datos.
